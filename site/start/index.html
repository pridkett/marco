Quickstart

Make your first DNS lookup.

Try Marco locally before pointing any devices at it. You’ll need Git, Go 1.25 or newer, OpenSSL, and dig.

Build and configure Start Marco Ask for a name Move to your LAN

1. Build and configure

Build from source and make a private demo directory. The example binds DNS to 127.0.0.1:1053 and the HTTPS console to localhost:8443.

For internet lookups, replace pools.resolver[0].address and serverName in marco.desired.json with your DNS-over-TLS provider’s IP address and verification hostname. The example’s placeholder works for the local lookup below. Marco seeds a new data directory from this file on the first run.

2. Start Marco

Generate a temporary certificate for the demo console, then validate the config. Use a certificate valid for your admin hostname when you deploy on the LAN.

Run this line on its own. Choose a password when prompted and use it to sign in as admin. The command passes the generated hash directly to Marco.

3. Ask for a name

Leave Marco running and run this in a second terminal. The example record should return 192.0.2.10.

Trust the demo certificate in your browser and open https://localhost:8443 to see the query in the console.

4. Move to your LAN

Set dns.listen to your LAN address and port 53, and set dns.allow to the client CIDRs Marco should serve. Verify that a device on the LAN can query it before updating your DHCP or router DNS settings. On Linux, give the service permission to bind port 53.
