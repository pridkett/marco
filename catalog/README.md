# Service catalog

`services.json` is an unmodified snapshot of the [AdGuard Host Lists Registry service catalog](https://adguardteam.github.io/HostlistsRegistry/assets/services.json) retrieved on November 19, 2026.

The SHA-256 digest is `883c00ae79280e3cf7db69cbe3da31dc34c98592d7b973b15c28416b39b30f5a`. The snapshot contains 142 services, 12 categories, and 2,406 rules.

The registry's GPLv3 license is distributed alongside the data. The [registry repository](https://github.com/AdguardTeam/HostlistsRegistry/tree/main/services) contains the original service definitions. Service logos identify their respective services. Marco reads this catalog as a separate file at startup.
